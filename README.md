# c0lornote-social-hub-b4fab374

## Getting started

Requires Node.js & npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
# Clone the repository
git clone https://github.com/MarbleLabs1/c0lornote-social-hub-b4fab374.git
cd c0lornote-social-hub-b4fab374

# Install dependencies
npm i

# Start the development server
npm run dev
```

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Deployment

Build with `npm run build` and deploy the `dist` folder to your host of choice.
